# 📊 YouTube Analytics Dashboard – Power BI

## 📌 Project Overview

This project analyzes global YouTube channel statistics using
Microsoft Power BI.

The dashboard focuses on channel performance, video views,
uploads, subscribers, rankings, and engagement metrics.

## 🎯 Objectives

- Analyze YouTube channel performance
- Identify channels with high upload volumes
- Analyze video view rankings
- Calculate average views for the last 30 days
- Compare channel types
- Analyze views per subscriber
- Explore category-wise performance
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
- CSV Dataset
